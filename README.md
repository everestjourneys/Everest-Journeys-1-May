# Everest Journeys — Website V2

This package is a complete multi-page static website.

## Upload to GitHub
Extract this ZIP and upload **all files and the `assets` folder** to the root of your repository.

Required structure:
- index.html
- about.html
- services.html
- industries.html
- automation.html
- resources.html
- contact.html
- style.css
- script.js
- robots.txt
- sitemap.xml
- llms.txt
- assets/logo.png

## Logo
The original supplied Everest Journeys logo is preserved as PNG (1254×1254). It is used in the header, loader and footer without distortion or recoloring.

## Design
White + Deep Navy #0B1F3A + Blue/Cyan #1687E8 / #20B9D8 + Orange-Gold #F59E0B / #F97316.
The visual language uses glassmorphism, subtle grids, connected nodes, funnels, CRM cards and restrained motion.

## SEO / AEO / GEO foundations
- Page-specific title and meta description
- Canonical URLs
- Index/follow directives
- Open Graph basics
- Organization / WebSite / WebPage / Service structured data
- robots.txt
- sitemap.xml
- llms.txt
- Search-intent-oriented service and industry copy
- FAQ content written as direct questions and answers
- Internal links between services, industries, automation, resources and contact
