# Everest Journeys — Complete Static Website

## Upload to GitHub
Upload the **entire folder contents** to the root of your GitHub repository. Do not upload only `index.html`.

Structure:
- index.html
- about.html
- services.html
- industries.html
- automation.html
- resources.html
- contact.html
- style.css
- script.js
- robots.txt
- sitemap.xml
- llms.txt
- assets/logo.jpg

## Deploy
For Netlify, publish the repository root. No build command is required.
